THE RITE OF INSTALLATION

How to install Brain Rotter Pro

  1. Download BrainRotterPro.zip (1.5 MB).
  2. Extract the zip. Move the BrainRotterPro folder into World of Warcraft\_retail_\Interface\AddOns\. On Windows this is usually C:\Program Files (x86)\World of Warcraft\_retail_\Interface\AddOns.
  3. Make sure the folder sits directly inside AddOns, not in a folder inside a folder.
  4. Restart World of Warcraft or type /reload.
  5. Type /rot and press Spew. Please rot responsibly: aim it at willing guildmates, not strangers.
Steam Deck faithful: the AddOns folder is inside the Proton/Wine prefix where Battle.net is installed, under the same World of Warcraft/_retail_/Interface/AddOns path. Switch to Desktop Mode and move the folder there.
QUESTIONS
Why do I have to click for /say?

World of Warcraft only lets addons speak in /say outside instances when you press a key or click. The SAY button (or a key binding) delivers the waiting line with one click.

Can I see the lines without posting them?

Yes. Set the channel to your own chat window and the rot stays between you and the Coil.
