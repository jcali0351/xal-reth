Sign in to edit the site

The site lives on GitHub, so your GitHub key is your login. Every change you save goes straight to the live site (it shows up in about a minute).

How do I get a key? (one time, 2 minutes)
  1. Open GitHub › Settings › Fine-grained tokens › Generate new token.
  2. Name it Sanctum Editor and pick an expiration (a year is fine).
  3. Under Repository access choose Only select repositories and pick xal-reth.
  4. Under Permissions › Repository permissions set Contents to Read and write. Nothing else is needed.
  5. Press Generate token, copy it, and paste it above.

The key only works on this one site and can be deleted on GitHub at any time. It is never saved in the site's files.

Guild Bank

Bring the Coil Ledger's record of the guild bank to the website. Each upload updates the gold and the tabs, and adds any new ledger entries to the history (nothing already recorded is doubled).

  1. In game, with the Coil Ledger addon installed (1.3.0 or newer), open the guild bank and wait a few seconds until chat says the bank is recorded. Check that the gold it names matches the bank window; if not, type /ledger gold and the amount the window shows (e.g. /ledger gold 950123g 45s 6c).
  2. Either type /ledger, press Ctrl+C and paste below (best: always the newest record), or type /reload (or log out) and upload the file World of Warcraft\_retail_\WTF\Account\YOUR ACCOUNT\SavedVariables\CoilLedger.lua. The game only writes that file on /reload or logout, so without one it still holds an older record.
  3. Check the summary, then press Save & publish. Item pictures are fetched from Blizzard a minute or two later.
